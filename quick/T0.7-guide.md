## Step 2：取 secret

请在**你自己的终端**里执行，不要用 Claude Code 的 `!` 前缀，这样 secret 不会进入对话。每条命令都是单行，整行复制；`--region`、`--output text`、`--no-cli-pager` 都不能省，否则本机 CLI 配置可能让命令没有任何输出（T0.7 实测）。凭证必须属于账号 `890717383483`。

```bash
# client A secret
aws cognito-idp describe-user-pool-client --region us-east-1 --user-pool-id us-east-1_btuTL63V3 --client-id 2q9be1ub7s5nh8ph4sl87uemr2 --query UserPoolClient.ClientSecret --output text --no-cli-pager
# client B secret
aws cognito-idp describe-user-pool-client --region us-east-1 --user-pool-id us-east-1_btuTL63V3 --client-id 4bf7hnvsugn9trphjtmsfldb4s --query UserPoolClient.ClientSecret --output text --no-cli-pager
# demo 用户名和密码
aws secretsmanager get-secret-value --region us-east-1 --secret-id doris-mcp/cognito-demo-user --query SecretString --output text --no-cli-pager
```

## Part A：Cloud Connector + User auth（主路径）

1. 打开 **Customize → Connectors → Create → Cloud Connector → MCP**，名称填 `doris-mcp`，URL 填上面的 MCP URL。
2. 鉴权选 **User authentication**，填 client A 的 ID 和 Secret，以及 Token URL、Authorize URL。
3. **记下 UI 上显示的 Redirect / Callback URL。** 如果它和上面的 `Callback (now)` 不一样，先停下来告诉我。我改好 Cognito 的回调地址后（会先走 GATE）你再继续。
4. 用 `demo` 用户登录并授权。
5. 在连接器详情里启用 `doris___net_check`，新工具默认是禁用的。
6. 新建一个对话，输入：「调用 doris___net_check 检查 Doris 连通性，原样给出结果」。应该返回 `mysql.ok=true` 和 `http.ok=true`。

如果鉴权失败，把错误信息告诉我，特别是提到 scope 的那种。我会按计划逐步处理，每一步都会先走 GATE。

## Part B：Cloud Connector + Service auth

- 新建连接器 `doris-mcp-svc`，URL 相同。
- 鉴权选 **Service authentication**，填 client B 的 ID、Secret 和 Token URL；如果 UI 要求填 scope，填 `doris-mcp/invoke`。
- 启用工具，调用一次。验证完可以先禁用。

## Part C：Local stdio（备份路径）

前提：Quick 桌面版所在的电脑上装了 `uv`，并且有一个 AWS profile `doris-demo`，它有权限对 Runtime 调用 `InvokeAgentRuntime`。最小权限策略见 `infra/policies/local-proxy.json`，把 `${RUNTIME_ARN}` 替换成下面这个值：

```
arn:aws:bedrock-agentcore:us-east-1:890717383483:runtime/dorismcp_dorismcp-ILgkSAFotU
```

推荐用 SSO profile。如果需要一个专用 IAM 用户，告诉我，我来准备命令（走 GATE）。

1. 先在本机终端验证 proxy 能启动：
   ```bash
   AWS_PROFILE=doris-demo uvx mcp-proxy-for-aws@latest 'https://bedrock-agentcore.us-east-1.amazonaws.com/runtimes/arn%3Aaws%3Abedrock-agentcore%3Aus-east-1%3A890717383483%3Aruntime%2Fdorismcp_dorismcp-ILgkSAFotU/invocations?qualifier=DEFAULT' --service bedrock-agentcore --region us-east-1 --timeout 55
   ```
   能启动、不报错就行，按 Ctrl-C 退出。
2. 打开 **Customize → Connectors → Local → Import**，导入仓库里的 `quick/local-connector.json`（已生成，profile 名是 `doris-demo`；如果你的 profile 名不同，告诉我，我重新生成）。
3. 启用工具并调用一次。这条路径的工具名是 `net_check`，没有 `doris___` 前缀。
